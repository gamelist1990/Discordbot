Bundled font assets for server-status image generation.

- `NotoSansJP[wght].ttf`
  Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
  License: SIL Open Font License 1.1
- `NotoSansJP-OFL.txt`
  Upstream license text for the bundled font
- `STIXTwoMath-Regular.otf`
  Source: https://github.com/stipub/stixfonts/tree/v2.13b171
  License: SIL Open Font License 1.1
  Used for Mathematical Alphanumeric Symbols such as `𝒶`, `𝓎`, and `𝟝` so
  Quote cards render consistently on Windows and Linux/Ubuntu.
- `STIXTwoMath-OFL.txt`
  Upstream license text for the bundled STIX Two Math font.
