# Universal Image Creation Skill

このSkillはイラスト、図案、ロゴ、アイコン、サムネイル、バナー、ポスター、図解、写真装飾など**すべての画像制作**に適用する。特定のスタイル・媒体・題材を標準として強制しない。ユーザーの指定が最優先。

## 制作 (Create)

1. **目的を読み取る**：誰に何を伝える画像か、必須要素と任意要素、最も見せたい被写体、想定媒体、参考画像、縦横比、指定テキスト、色、雰囲気を整理する。明示されない情報は勝手に足さない。簡単な依頼は簡単に仕上げる。
2. **画像を理解する**：元画像があるときは主要被写体、既存の文字・ロゴ・UI、余白、明暗、視線誘導を先に確認する。元画像の重要箇所を隠さず、指定のない変更・商品名や日付の捏造・重複掲載をしない。元画像を加工する依頼なら、その画像を素材として使い、描き直した偽物で置き換えない。
3. **画面を設計する**：主役→補助→背景の視覚的優先順位、焦点、配置、余白、重なり、コントラストを決める。必要なら非対称・遠近・大胆なトリミングも使う。何もかも中央寄せしたテンプレート、同じ帯・枠・バッジの乱用は避けるが、意図されたデザインは尊重する。
4. **表現を選ぶ**：依頼に合うスタイルを選択する。ミニマル、可愛い、写実的、派手、漫画的、レトロ、サイバー、手描き風、ゲーム風などを自然に使い分ける。「どんな画像もシンプルに」「必ず大見出しを入れる」「常に2色」など一律のルールは設けない。
5. **文字は必要なときだけ**：指定された文字は綴り・表記を忠実に保つ。媒体に合ったフォント・字間・行間・行分けを選び、縮小表示でも目的に応じて読めるか考える。文字を必要以上に追加せず、読みづらい装飾や意味のない説明の重複を避ける。独自レタリングはSVGパスでもよい。
6. **画像を実際に制作する**：使用可能なツールでSVGや画像編集操作を組み立てる。簡素な図形の寄せ集めで済ませず、必要なら曲線、立体感、影、マスク、グラデーション、反復パターンなどを使う。元画像の色調補正が必要ならSharp等の画素処理（photo_brightness/photo_saturationまたはimage_editorのmodulate等）を使い、透明な色面で代用しない。無意味なパーツは増やさない。
7. **完成画像を見て仕上げる**：実際の画像を視覚レビューできる場合、題材、バランス、配色、見切れ、誤字、元画像の保持を確認する。レビューの具体的な欠陥を直す。視覚確認できない経路では確認したふりをしない。単なる好みで無限に作り直さず、良い部分を維持する。
8. **納品は実物だけ**：「作るね」「完成した」は成果物ではない。利用できる構造化ツール（Staff AIではdraw_image、常駐チャンネルAIではimage_editorとupload_image）を実行し、実際の投稿結果で確認する。実行できないならその理由を正直に伝える。

## レビュー (Review)

- **依頼への一致**：目的、明示された被写体・テキスト・スタイル・サイズ・元画像の扱いが守られているか。余計な要素を勝手に追加していないか。
- **視覚的な強さ**：見た瞬間に主役が分かり、構図と余白が意図に沿い、完成品としてまとまっているか。ラフな手描き風など意図された不整合は欠陥としない。
- **文字と情報**：文字が実際に読めるか、誤字・記号化け・はみ出し・重複がないか。文字のない画像には文字の追加を要求しない。
- **品質と技術的欠陥**：不自然な重なり、切断、低品質なシルエット、ぼやけ、ノイズ、変な余白、背景との同化、破綻した比率や色を検出する。ただし作風として意図された表現は尊重する。
- **元画像がある場合**：主要被写体・既存の文字やロゴが保持され、不要な上書き、偽造、過度な装飾、見せ場の遮蔽がないか確認する。編集と再生成を取り違えていないか。
- **用途への適合**：サムネなら小サイズの訴求、ロゴなら識別性、図解なら正確性、アイコンならシルエット、写真なら自然な補正、ポスターなら情報の階層を評価する。ただし用途固有の押し付けは避ける。
- **評価**：明らかな欠陥のみ具体的な修正点を最大5件。良い画像にはPASSを出し、むやみに修正を要求しない。直すときは完成済みの良い部分を壊さない。
