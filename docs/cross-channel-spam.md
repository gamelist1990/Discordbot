# チャンネル横断スパム対策

アンチチートに `crossChannelSpam` を追加。アンチチート全体が有効なサーバーでは初期状態で有効です。
管理画面の「チャンネル横断スパム」から有効/無効、件数、秒数、必要チャンネル数、加算スコア、削除を変更できます。

初期設定:

- 同じユーザーが120秒以内に同文を2件以上、2チャンネル以上に投稿すると検知。
- 内容が違っていても10秒以内に6件以上、2チャンネル以上に投稿すると検知。本文なしの添付投稿も連投件数に含めます。
- 1検知につきスコア3。削除は検知設定とアンチチートの自動削除設定に従います。処罰・過去投稿の削除は既存ポリシーに従います。

サーバー・ユーザーごとに履歴を管理し、別ユーザー/別サーバーの投稿は合算しません。
スレッドも投稿先チャンネルID単位で集計します。Bot、除外ロール、除外チャンネルは既存の除外設定に従います。
本文の大文字小文字、全角半角、連続空白、一部のゼロ幅文字の違いを正規化します。画像バイトの同一性判定はこの検知では行いません。
編集で本文を同じに変更した場合も検査し、同じメッセージの再通知は新規投稿に数えません。
投稿時刻を基準に集計し、編集しても監視期間を延長しません。
投稿履歴はメモリ上で最大500件/ユーザー。期限切れは除去し、Bot再起動時にリセットします。

横断判定は専用の直列処理で先に実行し、以前の投稿のAI応答待ちに遮られません。
検知ログには件数、対象チャンネルID、メッセージIDを記録します。

# 点滅GIF

点滅GIF検査のMB制限を撤廃。以前の `gifFlash.config.maxFileSizeMb` が保存されていても使用しません。
管理画面のMB入力欄を削除し、取得待機時間の設定を追加しました。
通信タイムアウト、解析フレーム数、画像デコードの画素数制限は引き続き適用します。
Discord自体のアップロード上限は変わりません。AIコンテンツフィルター・重複画像検知のサイズ設定は別です。

検証コマンド:

```powershell
npx tsx --test tests/cross-channel-spam.test.ts tests/content-safety.test.ts tests/anticheat-load.test.ts
npm run web
```

クロスチャンネルの同文拡散、本文なしを含む連投、ユーザー/サーバー分離、期限切れ、編集、
AI待機中の処理、旧MB設定がある状態での8MB超GIF検査をローカルテストで確認しています。
Discord実サーバーでの投稿・削除テストは行っていません。
