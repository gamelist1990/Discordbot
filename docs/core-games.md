# Coreゲームの終了と清掃

## オセロ

- ランクマッチの先手・後手はランダムに決定します。
- 「投了（自分の負け）」は確認付きです。参加者本人だけが確定でき、相手の勝利としてレートを記録します。
- パスは自動処理します。Botの手番が続く場合も、人間が置けるか終局するまで進行します。
- 古い手番のボタン、別の部屋からの操作、参加者以外の着手は拒否します。合法手が20を超える場合は選択メニューで全候補を表示します。
- 最終操作から1時間の無操作は手番側の時間切れ負けです。部屋作成からの一律1時間制限ではありません。
- 募集は約5分で終了・清掃します。終局・投了・時間切れ・管理停止は約5分後に清掃します。募集退出は即時清掃です。
- セッションと削除予定は `corefeature/othello/sessions` に保存し、再起動後に復元します。清掃処理は30秒間隔で確認し、権限不足や一時エラーは記録して再試行します。
- ランク結果は対局ID単位で重複を防止します。結果保存とセッション保存の間に再起動しても二重加算しません。
- Botには部屋の閲覧・送信・履歴閲覧・チャンネル管理権限が必要です。サーバー側で権限を変更した場合、ログを確認してください。

## 性格診断

- 評価・追加質問・確信度調整に `GEMMA_MODEL` (`src/config.ts`) を明示指定し、他モデルへの自動切り替えは行いません。
- 診断結果のJSONは検証し、不正な形式なら1回再要求します。AIが最終判定を返せない場合に固定の性格タイプを捏造することはありません。
- AI応答待ちの間は無操作による部屋削除を抑止します。通信失敗時は回答を保持し、再送して再試行できます。
- 再起動時に無操作・結果後清掃の残り時間を復元します。削除失敗時は1分後に再試行します。

## 削除した機能

レスバは実装・登録・パネル案内・コマンドの選択肢から削除しました。既にDiscordに投稿済みのパネル表示を更新する場合は、Coreパネルを再投稿してください。古いレスバのボタンは新規セッションを開始しません。

この変更は既存のDiscordチャンネル、ロール、過去データを一括削除しません。特に旧バージョンで再起動前に作られ、保存情報が残っていないオセロ部屋は安全に所有確認できないため自動削除対象にしません。
