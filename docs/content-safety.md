# AIコンテンツフィルター（jev）

管理画面のアンチチート設定で有効にします。既存の有効/無効・除外設定は維持します。
モデルは `pexAi.contentSafetyModel`（既定 `jev`）。無料公開されたValen 0.8Bの意思決定APIを使用します。

## 判定

- 6カテゴリの有無をNoul、強さをScoreで評価します。会話生成やsubmit_verdictツールは使用しません。
- 有無の確率0.5未満はスコア0、それ以外は `min(有無の確率, 強さ/3)` を使用します。
- 既存のカテゴリ別しきい値が判定を決めます。説明は結果から組み立て、具体的な画像内容を自由文で生成しません。
- 加点は初期OFFの既存設定を使い、対象カテゴリの段階評価と上限から算出します。
- 独自ルールの不正・欠落した結果、API失敗、不完全な判定を無害と埋めません。

## 投稿の扱い

既存のネタバレ代理投稿・削除モードを使用します。変更された投稿に古い結果を適用しません。
本文・引用・否定・画像・キャプションを保全し、APIの413はフレームを分割して全結果を集約します。
検査失敗時に元投稿を保全する処理、類似・完全一致キャッシュを維持します。
モデルと質問定義・採点設定が変わると旧判定を再利用しないようcache scopeを設定しています。

## 接続

`pexAi.endpoint` と既存APIキーを使用します。画像はBotで取得したbase64 image data URLを送ります。
公開jev APIはローカルパスや外部URLを直接受け付けません。上限4096入力トークン、リクエスト32MiB、画像1枚8MiB。
チャンネルAIにはGeminiを使用し、コンテンツ検査の画像処理は会話用visionModelから独立しています。

関連33テスト通過。実APIで挨拶・物体破壊を違反なし、直接の危害予告を脅迫・暴力として検出することを確認。
