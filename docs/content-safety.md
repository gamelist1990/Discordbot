# AI コンテンツ検査 — LFM3（2026-10-30）

## 経路

Discord Bot `ContentSafetyDetector.ts` → `LfmContentClassifier.ts` → HomePC EndPoint `/v1/chat/completions` → LFM3-VL-2B（`lfm3`）。
テキスト、静止画像、GIF、MP4 の全検査を同じモデルに統一します。Jeff / Jev / Qwopus / Gemma の分類器は撤去済みです。
`pexAi.contentSafetyModel` の既定は `lfm3`。旧 `jev` / `jeff-base` も起動時に補正します。

## 出力と判定

| カテゴリ | 主な対象 |
| --- | --- |
| `suggestive` | 性的な誘い・性的な接触やポーズ |
| `explicit` | 露骨な性的描写 |
| `harassment` | 個人に向けた侮辱・嫌がらせ |
| `hate` | 属性を理由とする集団への憎悪・差別 |
| `threat` | 具体的な身体的危害の予告 |
| `violence` | 血まみれの傷害・殺害・残虐行為の描写 |

モデルは各カテゴリを 0～1（目安 0 / 0.33 / 0.67 / 1）で返し、`explanation` と `customRuleViolations` も JSON schema 必須フィールドです。
**旧 Jeff の Noul/Score 2段階方式は使いません。** 説明文はモデルが日本語で生成します。
既存のカテゴリ別しきい値、ネタバレ代理投稿・削除モード、加点の有効/無効を維持します。LFM3 は2Bの zero-shot 判定なので誤検知・見逃しに注意してください。

## 画像・動画

静止画像をデータ URL として送信します。GIF はフレーム抽出、MP4 は `ffprobe` / `ffmpeg` で均等間隔の JPEG フレームを抽出し、フレームシートにまとめます。
サンプリングでは短時間の違反シーンを見逃す可能性があります。MP4 検査実行ホストに ffmpeg と ffprobe が必要です。
取得済みメディアを検査に渡し、未検証の外部 URL やローカルファイルパスは LFM3 に渡しません。

## 障害・保全

502 / 503 / 504 の場合、判定期限の残りがあれば1度再試行します。API 障害、JSON 不正、判定値欠落、画像ダウンロードや変換の失敗を「安全」として扱いません。
投稿の保全、遅延再検査、メッセージ変更時の処理、キャッシュは既存の処理に委ねます。
本番の自動削除を有効にする前に、無害な文、侮辱、実際の脅迫、通常画像、GIF、MP4、独自ルールを使った動作確認と閾値調整を実施してください。

関連: [ai-models.md](./ai-models.md)、`src/core/anticheat/LfmContentClassifier.ts`。

## メンション単独投稿の誤検知対策（2026-10-30）

Discord のユーザーメンションだけを含む投稿は、サーバールールがメンション自体を明示的に禁止していない限り、文章分類を省略します。メンションに加えて本文に暴言などがあれば通常どおり検査し、画像・GIF・MP4 の添付検査も省略しません。
独自ルールが未設定、またはルール本文を取得できなかった場合、LFM3 が誤って返した独自ルール違反は採用しません。モデル用指示を更新し、過去の分類キャッシュとは別スコープにしています。


## 前後の会話を使う判定と処分前の再確認（2026-10-31）

- 同じチャンネルの投稿を Discord API のメッセージ周辺取得で読みます。現在の投稿の前後それぞれ最大4件、前後12分以内、各投稿の本文は240文字まで。投稿者IDと時刻を含め、Bot/ウェブフック投稿は除外します。
- 通常の短い文章は取得前に約1.8秒の猶予を設け、直後の返信も参照しやすくします。投稿の返信先（存在する場合）も文脈として渡します。
- これらは **参考情報のみ** です。違反カテゴリ、独自ルール、加点は常に「現在の投稿」を対象として判定し、前後の人の発言を転嫁しません。ログイン・権限・取得失敗時は返信先のみで継続します。
- テキストのみで違反候補となったとき、判定中に到着した返信を処分直前に取得し直します。文脈が変化していたら古い陽性結果を破棄し、現在の投稿を1回だけ再判定します。再判定が失敗した場合、既存の失敗時保全処理で削除・代理投稿を行いません。
- 異なる文脈の類似メッセージ間では判定キャッシュを共有しません。単なる「メンションされている」という短い不満は、LLMが性的表現や嫌がらせを誤生成しても誤検知しないよう保護します。ただし直接の侮辱や脅迫を含む投稿は引き続き検査します。

**制限**: 未来の投稿は取得できません。時間が大きく離れた後続の返信については初回判定に反映できません。また、前後の会話による情報量増加と再判定で処理時間が長くなる場合があります。

### LFM3 思考モード

HomePC の user systemd `lfm-vision.service` の起動スクリプトで `--reasoning on --reasoning-budget 128` を有効化しています。`LfmContentClassifier.ts` は `reasoning_effort: low`、出力上限896トークンを指定し、内部の思考ではなく最終JSON本文だけを判定に使用します。思考のみで最終JSONが欠けた場合は失敗として保全します。
