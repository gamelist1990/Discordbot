# AIコンテンツフィルター（Jeff-base）

管理画面のアンチチート設定で有効にします。既存の有効/無効・除外設定は維持します。
テキスト判定はJeff-base（`pexAi.contentSafetyModel`、既定 `jeff-base`）を使用します。古い設定値 `jev` は `jeff-base` として扱います。画像や動画を含む判定だけGemma 4 E4Bを使います。

## 判定

- 6カテゴリの有無をNoul、強さをScoreで評価します。会話生成やsubmit_verdictツールは使用しません。
- 有無の確率0.5未満はスコア0、それ以外は `min(有無の確率, 強さ/3)` を使用します。
- 既存のカテゴリ別しきい値が判定を決めます。説明は結果から組み立て、具体的な画像内容を自由文で生成しません。
- 加点は初期OFFの既存設定を使い、対象カテゴリの段階評価と上限から算出します。
- 独自ルールの不正・欠落した結果、API失敗、不完全な判定を無害と埋めません。
- Jeffの一時的な502/503/504は同じ判定期限内で1回再試行し、それでも失敗した場合は元投稿を保全して通常の遅延再検査へ回します。

## 投稿の扱い

既存のネタバレ代理投稿・削除モードを使用します。変更された投稿に古い結果を適用しません。
本文・引用・否定・画像・キャプションを保全し、APIの413はフレームを分割して全結果を集約します。
検査失敗時に元投稿を保全する処理、類似・完全一致キャッシュを維持します。
モデルと質問定義・採点設定が変わると旧判定を再利用しないようcache scopeを設定しています。

## 接続

`pexAi.endpoint` と既存APIキーを使用します。画像はBotで取得したbase64 image data URLを送ります。
APIにはBot側で取得した画像・動画データを送ります。ローカルパスや外部URLは直接渡しません。入力上限4096トークン、リクエスト32MiB、画像1枚8MiBです。
チャンネルAIにはGeminiを使用し、コンテンツ検査の画像処理は会話用visionModelから独立しています。

2026-10-17に推論先をA8のJeff-baseへ切り替えました。しきい値と質問定義は従来設定を維持しています。
旧方式の開発履歴は `WorkSpace/engineerDocs/discordbot/2026-10-14/` に保存しています。
詳細は [ai-models.md](./ai-models.md)。

## 動画

画像検査のスイッチでGIFとMP4も検査します。GIF/MP4は時間順の動画としてjevへ渡し、サーバーが16フレームを抽出して判定します。取得上限は既存のmaxFileSizeMb・maxImages。maxSampleFramesはアニメWebP用です。動画キャッシュは本文とbytesの完全一致だけ再利用します。ネタバレ再投稿は元ファイルを保持します。
