# ミルクホワイト UI

ホーム、サーバー設定、スタッフツール、ランキングと各一覧画面のレイアウトを更新しました。

- 背景はミルクホワイト、編集面は白、選択状態は淡いグレージュ。主操作はチャコール。暗色テーマでは文字のコントラストを保ちます。
- 設定は左ナビと編集面、スタッフは分類・検索とツール一覧、ランキングは上位の要約と行形式の一覧を使用します。
- 検索しても順位は元の順位を保ちます。スタッフのツール一覧はコマンドAPIの失敗に影響されません。
- API・保存先・認証条件は既存の仕組みを使用します。スクリーンショット確認ではブラウザ内だけのテストデータを使用しています。

## 検証

`npm run web` でビルドできます。

ローカルプレビューを起動：

```powershell
npx vite --config src/web/client/vite.config.ts --host 127.0.0.1 --port 5177 --strictPort
```

別ターミナルで表示・操作を検証：

```powershell
node tests/ui-redesign-smoke.mjs
```

7画面のPC/スマホ・明暗テーマ、横はみ出し、検索、保存、ランク別折りたたみ、メニュー遷移、API失敗時の表示を確認します。APIはすべてテスト内で差し替え、本番には書き込みません。画像出力先は `UI_REDESIGN_OUTPUT` で変更できます（既定は `test-results/ui-redesign`）。

フロントエンド全体の型チェックには、変更対象外の Profile/CardInspector と AntiCheat の既存エラー（未使用import、ES2020に対するArray.at）が残っています。
