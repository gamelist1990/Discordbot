# /staff ai の入力軽量化

全16ツールの登録とパラメーター定義は維持し、ツール説明と重複したシステム指示を短縮しました。固定指示は従来2,486文字から約550文字になりました。これは文字数の比較で、実際のトークン数はモデルのトークナイザーによって変わります。

- 履歴: 最大8,000文字から4,000文字。データセット4件・チャンネル6件を候補に、直近を優先。
- 保存メモ: 最大3,500文字から1,200文字。通常は本人プロフィールのみ、日次情報を尋ねられた場合に直近日次要約1件を追加。
- サーバー話し方: 初期設定の説明を省略し、実際の設定・学習内容・カスタム指定だけ送信。
- ツール説明: 長い例と重複ルールを短縮。全16ツールとパラメーターの制約は保持。
- スケジュール・Discord履歴検索・URL取得の説明を、システム側でも毎回重ねて送る処理を削除。

過去履歴の上限には参照用のシステム注記も含めます。直近1件が大きい場合も上限を超えません。現在の依頼、添付、明示された返信先をこの履歴予算で切ることはありません。メモの原本も変更せず、詳細はmanage_memoryで参照できます。事実確認、出典、ツール結果の成功確認、本人メモの範囲、現在時刻、予約とファイル出力の基本指示は維持しています。

入力上限エラーは専用メッセージで案内します。通信・認証・サーバーエラーを入力サイズの問題と断定しません。
