# AI判定ログ

AntiCheatの設定画面で「AI判定ログチャンネル ID」にスタッフ用テキストチャンネルのIDを入力して保存します。空欄で無効になります。Botには閲覧・メッセージ送信・埋め込みリンク・ファイル添付の権限が必要です。

AI検知を実行した投稿について、検知あり・検知なし・失敗・中止を専用チャンネルに送信します。AI検知が無効、除外対象、または先行する通常ルールの検知でAIが実行されない投稿は対象外です。既存の検知ログや違反ポイントの条件は変わりません。

要約にはAIが返した判定理由、モデル、検知器の待機を含む経過時間、入力・出力・合計トークン、リクエスト別tok/s、キャッシュ、加点を表示します。AIの内部思考ではなく、返された説明とスコア・閾値を記録します。

添付JSONにはカテゴリ別スコア、判定閾値、有効カテゴリ、画像フレーム数、キャッシュの種類と類似度、再試行・分割リクエストのHTTP状態・所要時間・使用量、エラーなどを収録します。totalElapsedMsは検知器の待機を含む時間、elapsedMsはスキャン時間です。ユーザー単位の処理キューに入る前からの時間は含みません。

tok/sは出力トークン数をAPIリクエスト全体の秒数で割った実効速度です。APIが使用量を返さない場合は取得不可とし、文字数から推定しません。再試行・分割分はそれぞれ記録し、すべてのリクエストから取得できた項目のみ合計します。キャッシュ命中や同時処理の共有では新しいAPI使用量を計上しません（sharedは別の投稿の実行結果を共有）。

実際の削除・再投稿の成否は既存の検知ログで確認してください。このログはAI判定時点の記録です。
